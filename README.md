## 📌 Problem Statement

Millions of citizens in Jharkhand face severe barriers when reporting everyday civic issues.

Official portals strictly require English or Hindi.

This excludes millions who speak regional and tribal languages like Santali, Bhojpuri, Nagpuri, Ho, Mundari, or Kurukh.

Existing citizen portals are overly complicated.

They require structured data input that strongly discourages rural participation.

Complaints submitted through generic channels often fail to reach the correct municipal body in time.

---

## 💡 The Solution

JantaSetu is a multi-lingual, voice-enabled civic incident reporting platform.

It is logically designed to streamline public grievance redressal across Jharkhand's 24 districts.

Citizens can record audio or type complaints natively in their preferred language.

The system automatically processes and normalizes these inputs into standardized administrative cases.

The entire site navigation and UI dynamically adapt to regional languages with zero page reloads.

Incident reports are geo-tagged and displayed on a real-time interactive district map.

The backend logic automatically routes priority cases straight to the relevant authority dashboard.

---

## ✨ Key Features

* **Real-time Translation:** Integrated client-side localization engine covering all portal pages.
* **Live Incident Board:** Public display of recent community reports with original submission dialects.
* **Interactive Map:** Geographic visualization using Leaflet map coordinates across key districts.
* **Authority Dashboard:** Centralized triage board categorizing open issues by priority, status, and department.

---

## 🛠️ Tech Stack & Architecture

* **Frontend UI:** HTML5, CSS3 (Custom Variables), Vanilla JavaScript.
* **Interactive Maps:** Leaflet.js with CartoDB Dark Matter tile basemaps.
* **Localization Engine:** Hybrid engine combining Google Translate API & fallback dictionary.
* **Data Persistence:** Web Storage API (`localStorage`) for user language preference state.
